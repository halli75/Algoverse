## Construction recipe (Cell 10) — re-derive in our Colab

```text
r_dir[l]  = unit( mean_resid(harmful_train) - mean_resid(harmless_train) )
a_dir[l]  = unit( mean_resid(DESCRIBE, neg_imgs) - mean_resid(DESCRIBE, neu_imgs) )
a_perp[l] = unit( a_dir[l] - (a_dir[l]·rhat) rhat )
steer coeff = alpha * norms[l]   # norms = ||resid_post last-token|| on a harmful prompt
jailbreak  = steer(a_perp, -ALPHA_JB)   # negative = toward positive/benign affect
```

N_DIR=128, N_EVAL=100, N_IMG=60, seed for random control = 7.

## Locked protocol decision (2026-07-29)

**Match Charlotte:** mean-over-layers `a⟂`/`r` projection + multi-layer norm-scaled steer (`ALPHA_JB=0.008`). Primary localization window `[8,20)`. Do not use Arnav last-token-only coeff-20 for Steps 2–4 on these axes.
